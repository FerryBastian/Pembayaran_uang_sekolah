# Prompt Engineering Transformation Plan

## Objective
Transform user-provided input into a high-quality, structured, and effective AI prompt by applying professional prompt engineering techniques.

## Steps

### 1. Intent Analysis
- Parse the user's input to identify the core task, goal, and desired outcome.
- Extract key entities, actions, and any implicit requirements.
- Determine if the request is straightforward or requires clarification.

### 2. Context Enrichment
- Add necessary background information, domain knowledge, or situational details that the AI needs to know.
- Include relevant constraints, assumptions, or scope boundaries.
- Ensure the context is concise but sufficient for accurate understanding.

### 3. Persona Specification
- Define a clear and appropriate persona for the AI (e.g., "You are a senior software engineer with 10 years of experience in scalability").
- Align the persona's expertise, tone, and perspective with the task.
- State the persona explicitly at the beginning of the prompt.

### 4. Output Format Definition
- Specify the exact format, structure, and style of the expected response.
- Use examples, templates, or schema definitions when applicable (e.g., JSON, markdown, bullet points).
- Clarify any non-negotiable formatting requirements.

### 5. Constraint & Guardrail Setting
- Prevent hallucinations by instructing the AI to:
  - Stick to provided information and avoid making up facts.
  - State assumptions clearly if needed.
  - Decline to answer if insufficient data, or request clarification.
- Include any ethical, safety, or domain-specific constraints.

### 6. Chain-of-Thought (CoT) Framework
- Mandate step-by-step reasoning before delivering the final answer.
- Prompt the AI to:
  - Break down the problem.
  - Consider multiple angles or approaches.
  - Weigh trade-offs.
  - Validate intermediate conclusions.
- End with a clear, final output that follows the defined format.

### 7. Prompt Construction
- Combine all elements into a single, coherent prompt with clear sectioning.
- Use formatting (headings, bullet points) to improve readability.
- Ensure the prompt is self-contained and ready for immediate use.

### 8. Review & Refinement
- Review the crafted prompt against criteria: clarity, precision, depth, and alignment with user intent.
- Optionally, simulate the AI response to test effectiveness and adjust accordingly.
- If the original user input is ambiguous, ask targeted clarifying questions before finalizing.

## Execution Notes
- If the user input is too vague, ask concise clarifying questions before proceeding.
- Maintain a professional, technical tone throughout the prompt.
- Prioritize accuracy and reliability over creativity unless specified otherwise.
- Document any assumptions made during transformation.
